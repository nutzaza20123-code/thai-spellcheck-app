# โปรแกรมตรวจอักษรไทย-อังกฤษ (Word)

โปรแกรมตรวจสอบคำที่มีแนวโน้มสะกดผิดหรือสะกดผิดแน่นอน ในไฟล์ Word (.docx) ทั้งภาษาไทยและอังกฤษ
ทำงานแบบ **ออฟไลน์ล้วน** ไม่ต้องต่อเน็ต เหมาะสำหรับพนักงานทั่วไปที่ไม่ต้องติดตั้ง Python หรือไลบรารีใดๆ

## วิธีใช้งาน (สำหรับพนักงาน)

1. ดับเบิลคลิกไฟล์ `ThaiSpellCheckApp.exe`
2. กด "เลือกไฟล์" แล้วเลือกไฟล์ .docx ที่ต้องการตรวจ
3. กด "▶ เริ่มตรวจสอบ"
4. รอสักครู่ ระบบจะสร้างไฟล์ผลลัพธ์ 2 อย่าง:
   - ไฟล์ Word ที่มีการเน้นสีคำที่พบและคอมเมนต์อธิบาย
   - ไฟล์ Excel สรุปรายการทั้งหมด พร้อมระดับความเชื่อมั่น (สูง/กลาง/ต่ำ)
5. กดปุ่มเปิดไฟล์ผลลัพธ์ หรือเปิดโฟลเดอร์ผลลัพธ์ได้จากในโปรแกรม

กดปุ่ม "ℹ️ ข้อจำกัด/วิธีใช้" ในโปรแกรมเพื่อดูคำอธิบายข้อจำกัดของการตรวจภาษาไทยโดยละเอียด

## โครงสร้างโปรเจกต์ (สำหรับผู้ดูแลระบบ/พัฒนา)

- `spellcheck_engine.py` — เอนจินตรวจคำหลัก (โหลดพจนานุกรม, ตัดคำ, ตรวจสอบ, สร้างรายงาน)
- `gui_app.py` — หน้าตาโปรแกรม (tkinter) ที่พนักงานใช้งานจริง
- `build.spec` — ไฟล์ตั้งค่า PyInstaller สำหรับ build เป็น .exe
- `.github/workflows/build-windows.yml` — GitHub Actions workflow ที่ build .exe ให้อัตโนมัติบน Windows runner ทุกครั้งที่ push เข้า `main`/`master` หรือกด "Run workflow" เอง
- `requirements.txt` — ไลบรารี Python ที่ต้องใช้
- `พจนานุกรมเสริม_ตัวอย่าง.txt` — ตัวอย่างไฟล์พจนานุกรมเสริม (คำเฉพาะทาง/ชื่อเฉพาะที่ไม่อยากให้ระบบตีว่าสะกดผิด)

### ดาวน์โหลด .exe ที่ build ไว้แล้ว

ไปที่แท็บ **Actions** ของ repo นี้ → เลือก workflow run ล่าสุดที่ผ่าน (สีเขียว) → เลื่อนลงไปที่ "Artifacts" → ดาวน์โหลด `ThaiSpellCheckApp-windows`

### Build เองบนเครื่อง Windows (ถ้าไม่อยากรอ GitHub Actions)

```
pip install -r requirements.txt pyinstaller
pyinstaller build.spec
```

ไฟล์ผลลัพธ์จะอยู่ที่ `dist/ThaiSpellCheckApp.exe`

## ข้อจำกัดสำคัญ

การตัดคำภาษาไทยไม่มีเว้นวรรคระหว่างคำ ทำให้การตรวจมีความคลาดเคลื่อนได้บ้าง (ทั้ง false positive และ false negative)
โปรแกรมนี้จึงเป็น **เครื่องมือช่วยตรวจทาน** ไม่ใช่การพิสูจน์อักษรที่สมบูรณ์แบบ 100% ควรให้คนตรวจทานอีกครั้งก่อนใช้เอกสารจริง
